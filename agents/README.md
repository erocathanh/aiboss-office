# Agents Directory

This directory contains dedicated folders for all active seats in AIBOSS Office.

## Rules
- Each seat has its own real subdirectory: `agents/<seat_id>/`.
- Must be a real directory within the repository (no symlinks pointing outside the repository).
- Each seat directory holds its `SOUL.md` (authored in Track B and placed by PM), local settings, and operational instructions.
