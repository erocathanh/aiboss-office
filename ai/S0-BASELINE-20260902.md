## Cách tái lập và so tự động

Chạy từ gốc kho bằng `bash`. Lệnh này so manifest trong chính tài liệu với byte tại commit nền và in cả số file đã so lẫn số lệch; không dùng mắt để so hash.

```bash
python3 - <<'PY'
import hashlib
import re
import subprocess
from pathlib import Path

snapshot = Path('ai/S0-BASELINE-20260902.md').read_text(encoding='utf-8')
expected = re.findall(r'^([0-9a-f]{32})  (.+)$', snapshot, flags=re.MULTILINE)
mismatches = []
for wanted, path in expected:
    data = subprocess.check_output(['git', 'show', f'd9c3c7a:{path}'])
    actual = hashlib.md5(data).hexdigest()
    if actual != wanted:
        mismatches.append((path, wanted, actual))
print(f'da_so={len(expected)} lech={len(mismatches)}')
for path, wanted, actual in mismatches:
    print(f'LECH {path} expected={wanted} actual={actual}')
raise SystemExit(1 if mismatches else 0)
PY
```
